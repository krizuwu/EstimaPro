# EstimaPro - Sistema Web para Gestión de Estimaciones

[cite_start]**EstimaPro** es una aplicación web diseñada para centralizar la toma de requerimientos y automatizar el cálculo de estimaciones técnicas, orientada a desarrolladores freelance y pequeñas agencias[cite: 55, 266].

## Funcionalidades del MVP (Sprint 6)
- [cite_start]**Autenticación Segura:** Gestión de acceso mediante Firebase Auth[cite: 159, 303].
- [cite_start]**Gestión de Requerimientos:** Registro y clasificación técnica de funcionalidades[cite: 309, 319].
- [cite_start]**Motor de Estimación:** Cálculo automático basado en la complejidad de las tareas[cite: 325, 330].
- [cite_start]**Dashboard de Control:** Visualización de métricas y cumplimiento de objetivos SMART[cite: 333, 339].
- [cite_start]**Exportación Profesional:** Generación de vista para impresión/PDF de las estimaciones[cite: 341, 351].

##  Stack Tecnológico
- [cite_start]**Frontend:** Vue.js + Vite[cite: 115, 151].
- [cite_start]**Backend/Base de Datos:** Firebase (Firestore)[cite: 60, 73].
- [cite_start]**Metodología:** Scrum (6 Sprints de 2 semanas)[cite: 62, 298].

## Instalación
1. Clonar el repositorio.
2. Navegar a la carpeta `/estimapro`.
3. Ejecutar `npm install`.
4. Iniciar entorno de desarrollo con `npm run dev`.
